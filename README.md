# tdl GUI

`tdl GUI` 是 [iyear/tdl](https://github.com/iyear/tdl) 的本地网页操作界面。它不会替代 `tdl`，而是把常用的登录、聊天查询、消息导出、文件下载、记录预览、转发、上传和用户导出操作整理成网页表单，并在页面底部实时显示命令输出。

## 功能概览

- **登录**：支持 Telegram Desktop、验证码和二维码三种登录方式。
- **聊天列表**：列出并搜索群组、频道和私聊；选择后可自动填入导出与快速下载表单。
- **记录预览**：读取 `tdl chat export` 生成的 JSON，按图片、视频和其他文件筛选；已下载的图片和视频可直接预览，未下载的文件可单独下载。
- **下载**：支持 Telegram 消息链接、导出 JSON、快速导出后下载三种来源。
- **任务控制**：支持继续下载、重新下载、停止任务，以及在控制台中响应登录等交互提示。
- **导出**：按时间、消息 ID 或最近消息数量导出，并可从浏览器下载生成的 JSON。
- **转发、上传、用户导出**：覆盖 `tdl` 对应的常用参数。
- **本地设置**：配置 `tdl.exe`、会话目录、代理、命名空间、并发数、线程数、下载目录和端口。

## 运行要求

- Windows 10/11。
- Python 3.8 或更高版本；后端只使用 Python 标准库，无需安装额外依赖。
- 已下载可运行的 `tdl.exe`。
- 能正常登录 Telegram 的网络环境；如有需要，可在设置中填写代理。

## 快速开始

1. 克隆或下载本项目。
2. 编辑 `config.json`，至少确认 `tdl_path` 和 `tdl_home`；也可以先启动程序，再在“设置”页面修改。
3. 双击 `start.bat`，或在项目目录运行：

   ```powershell
   python server.py
   ```

4. 浏览器会自动打开本地页面：

   ```text
   http://127.0.0.1:8765
   ```

   如果端口 `8765` 已被占用，程序会依次尝试后续端口，并在启动窗口中显示实际地址。

5. 首次使用时，按下文“完成登录”在原生 PowerShell 中创建会话；已有有效会话时可以直接使用其他功能。

若只想启动服务而不自动打开浏览器，可设置环境变量：

```powershell
$env:TDL_GUI_NO_BROWSER = "1"
python server.py
```

## 配置说明

当前 `config.json` 示例：

```json
{
  "tdl_path": "D:\\ruanjian\\ruanjian\\tdl_Windows_64bit\\tdl.exe",
  "tdl_home": "D:\\file\\kaifa\\project\\ai\\telegram_dw\\tdl_home",
  "namespace": "default",
  "proxy": "",
  "pool": 8,
  "limit": 2,
  "threads": 4,
  "download_dir": "downloads",
  "host": "127.0.0.1",
  "port": 8765
}
```

| 字段 | 说明 |
| --- | --- |
| `tdl_path` | `tdl.exe` 的完整路径。 |
| `tdl_home` | 运行 `tdl` 时使用的 `USERPROFILE`；会话通常保存在 `<tdl_home>\.tdl\data`。 |
| `namespace` | `tdl` 命名空间；使用 `default` 时不会额外传入 `-n`。 |
| `proxy` | 可选代理，例如 `protocol://user:pass@host:port`。 |
| `pool` | DC 连接池大小。 |
| `limit` | 默认并发下载任务数。 |
| `threads` | 默认单文件下载线程数。 |
| `download_dir` | 默认下载目录；相对路径以项目目录为基准。 |
| `host` | Web 服务监听地址，默认仅监听本机。 |
| `port` | 首选 Web 服务端口。 |

网页“设置”页可以修改除 `host` 外的常用字段。保存后配置会写回 `config.json`。

## 推荐使用流程

### 1. 完成登录

登录成功后，`tdl` 会把会话写入 `tdl_home\.tdl\data`。网页界面只能使用与“设置”页面相同的 `tdl_home` 和命名空间；因此，建议先在原生 PowerShell 中完成一次登录，再启动或刷新网页。

> **Windows 网页界面的限制**：当前程序会把 `tdl` 作为隐藏子进程运行。`tdl` 的 Windows 账号选择器需要真实终端的方向键输入，网页底部的“控制台输入”不能模拟它。若 Desktop 登录显示 `Choose a user id` 后报 `Error: Incorrect function`，请按下面的 PowerShell 方法完成登录。验证码和二维码登录也建议在原生终端中执行，以便处理手机号、验证码或两步验证密码等交互。

先在 PowerShell 中设置与网页“设置”页一致的路径。以下示例中的路径应按本机配置替换：

```powershell
$tdl = 'D:\ruanjian\ruanjian\tdl_Windows_64bit\tdl.exe'
$env:USERPROFILE = 'D:\file\kaifa\project\ai\telegram_dw\tdl_home'
```

如果网页“设置”中的命名空间不是 `default`，请在下面每条命令末尾追加 `-n <命名空间>`，例如 `-n work`。

#### 方法一：复用 Telegram Desktop 会话

1. 完全退出 Telegram Desktop，包括系统托盘中的程序。
2. 执行以下命令；`-d` 填 Telegram Desktop 的 `tdata` 目录。若 Telegram Desktop 设置了本地锁密码，追加 `-p '你的本地锁密码'`。

   ```powershell
   & $tdl login -T desktop -d 'D:\ruanjian\ruanjian\telegram\Telegram Desktop\tdata'
   ```

3. 若列出多个账号，使用方向键选择账号并按 Enter。不要在 Git Bash、IDE 内置终端或网页控制台中执行此步骤。

#### 方法二：手机号与验证码

1. 执行：

   ```powershell
   & $tdl login -T code
   ```

2. 按终端提示输入完整手机号、Telegram 收到的验证码，以及启用两步验证时的密码。

#### 方法三：二维码

1. 执行：

   ```powershell
   & $tdl login -T qr
   ```

2. 在手机 Telegram 中打开“设置 → 设备 → 连接桌面设备”，扫描终端显示的二维码。若账号启用了两步验证，按终端提示完成验证。

三个方法任意一种显示登录成功后，回到网页并刷新页面；左下角状态显示“已登录”即可继续使用聊天列表、导出和下载功能。

### 2. 选择聊天

1. 在“设置”页确认 `tdl.exe` 和 Home 目录。
2. 打开“聊天列表”，点击“列出聊天”。
3. 使用名称、用户名或 ID 搜索，点击目标行完成选择。

### 3. 导出消息

“导出”页支持三种范围：

- 按起止时间导出。
- 按起止消息 ID 导出。
- 导出最近 N 条消息。

可通过过滤表达式仅保留包含文件、图片、视频或文档的消息。导出完成后，点击“下载 JSON”可把结果保存到浏览器下载目录。

### 4. 预览聊天记录

1. 在“记录预览”页填写导出的 JSON 路径和下载目录。
2. 点击“加载预览”。程序会读取消息中的文件名，并在下载目录及 JSON 所在目录中查找同名文件。
3. 使用“全部 / 图片 / 视频 / 其他文件”筛选记录。
4. 已存在的图片或视频可以直接打开预览；尚未下载的条目可以单独启动下载。

### 5. 下载文件

| 模式 | 用途 |
| --- | --- |
| `Message Links` | 粘贴一个或多个 Telegram 消息链接，每行一个。 |
| `Export File` | 使用一个或多个已导出的 JSON 文件，每行一个路径。 |
| `Quick Export + Download` | 先按聊天和范围导出消息，再自动下载其中的文件。 |

下载页还支持扩展名包含/排除、文件名模板、媒体组检测、倒序下载、跳过同名同大小文件、扩展名重写、Takeout 会话等选项。

使用导出 JSON 下载时，程序会把“聊天 ID + 消息 ID”写入项目目录下的 `.tdl-download-history.json`。下载开始前会扫描目标目录，把已经存在的最终文件自动补入记录；任务正常结束、报错或被停止时也会再次扫描，只记录已经完整落盘的文件，`.tmp` 等临时文件不会算作完成。这份记录与下载目录分离，所以把文件剪切到其他磁盘后，再次提交相同或包含重叠消息的 JSON 时，已完成项目仍会自动跳过。下载页会显示记录总数，并提供“清空记录”按钮；“重新开始”会绕过历史记录并重新下载。

“继续上次下载”和“重新开始上次下载”需要保留相同的消息链接或导出 JSON。继续下载会保留持久化历史记录，并让 `tdl` 处理未完成的项目；重新开始会绕过历史记录并重新提交全部项目。快速导出模式需要先得到 JSON，再切换到 `Export File` 模式继续。

## 其他功能

- **转发**：来源可以是消息链接或导出 JSON；支持直接转发、克隆发送、倒序、试运行、静默发送和内容编辑表达式。
- **上传**：上传一个或多个文件/目录；支持话题 ID、扩展名过滤、照片模式、上传后删除和说明文字。
- **用户导出**：按聊天用户名或 ID 导出频道/超级群组成员，可选择原始 MTProto 结构。

## 控制台与任务状态

- 页面底部控制台通过 SSE 实时显示 `tdl` 输出。
- 登录或其他交互式命令等待输入时，在控制台输入框中提交内容。
- 点击“停止”会终止当前 `tdl` 进程及其子进程。
- 后端同一时间只运行一个任务；如果已有任务正在执行，请等待完成或先停止当前任务。

## 项目结构

```text
.
├── server.py      # 本地 HTTP 服务、tdl 命令构建、任务与预览接口
├── index.html     # 单页 Web 界面
├── config.json    # 本地运行配置
├── start.bat      # Windows 启动脚本
├── downloads/     # 默认下载目录
└── tdl_home/      # 当前配置使用的本地 tdl Home 目录
```

## 常见问题

### 启动时提示找不到 tdl.exe

在“设置”页或 `config.json` 中，把 `tdl_path` 改为实际的 `tdl.exe` 完整路径，然后重新执行操作。

### 页面显示未登录

确认 `tdl_home` 指向正确的 Home 目录，并检查 `<tdl_home>\.tdl\data` 中是否存在会话数据。更换 Home 目录后通常需要重新登录。

### 预览中显示“未下载”

确认“记录预览”页填写的下载目录正确。程序会递归搜索该目录和导出 JSON 所在目录，并按文件名匹配本地文件。

### 端口被占用

服务会从配置端口开始向后尝试最多 20 个端口。请以启动窗口输出的地址为准。

## 使用边界

该界面按本地工具设计，默认只监听 `127.0.0.1`。不要把服务直接暴露到不受信任的网络；配置文件、导出记录和会话目录也不应提交到公共仓库。
